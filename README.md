# db

A simple TUI for managing sqlite databases

## Quick Start

Clone and install with Go

```bash
git clone https://github.com/stevedylandev/db
cd db
go install .
```

Run the command with a path to a sqlite file

```bash
db books.sqlite
```

## Features

- Browse tables and schemas
- Insert, update, or delete rows
